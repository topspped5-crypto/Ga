Gateway Admin + API Compatibility Update
=========================================
Added:
- Admin > Gateway System with separate Paytm and FamPay setup forms.
- Paytm setup fields: Shop Name, UPI ID, Merchant ID (MID).
- FamPay setup fields: Shop Name, UPI ID, Gmail, 16-character Gmail App Password.
- Connection tests, on/off, token regeneration, delete controls and API token display.
- API compatibility endpoints: /api/v1/payment/create, /api/v1/payment/status/{id},
  /api/v1/payment/verify.
- Authorization: Bearer token support.
- QR SVG and PNG endpoints.
- Updated user-facing /docs page and API_DOCUMENTATION.txt.
- Existing /api/v1/orders endpoints remain available.

Important:
- paytm.py and fampay.py are preserved byte-for-byte from the uploaded archive.
- payments.py, worker.py and core.py are preserved byte-for-byte.
- Existing merchant gateway setup and legacy API endpoints remain available.
- Set Admin > Settings > Public base URL to the deployed HTTPS URL.
- Use the platform API token only on your bot/server, never in public client code.

Compatibility note:
- This implementation's webhook signature is the existing X-Signature HMAC-SHA256
  of the raw body using the API token. It is not the timestamp + separate webhook-secret
  signature described in the supplied reference text.
- The documented idempotent retry behavior for repeated custom order_id values is not
  implemented by the original database schema; generate a unique order_id per payment.
